# Privacy Policy — OpenCode Gmail MCP

This OAuth application ("OpenCode Gmail MCP") is a personal automation tool owned and operated by Sean David Ram Singh (seandavidramsingh@gmail.com). It is used solely by the owner's own accounts to manage the owner's own content (YouTube uploads, channel metadata) and read the owner's own email via MCP integrations.

## What the app accesses
- YouTube Data API (scopes: youtube.force-ssl, youtube.upload) — to upload and manage videos on channels owned by the owner.
- Gmail read scopes where applicable — to read the owner's own inbox for workflow notifications.

## Data handling
- The app requests only the scopes listed above.
- No data is sold, shared, or transmitted to third parties.
- Tokens are stored locally on the owner's machine and never published.
- No analytics or tracking are performed.
